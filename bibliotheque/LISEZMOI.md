# Bibliothèque de fiches · Profile library

**FR** — Fiches partagées par les utilisateurs de DunenScope : chacune décrit un modèle (protocole, liaison, noms,
unités et échelles des lignes). Dans DunenScope : page **Autre appareil** → **Ouvrir une fiche…** →
**Bibliothèque en ligne…**. Les valeurs d'une fiche partagée ne sont jamais reprises. Pour proposer la vôtre : bouton
**Partager ma fiche…** de la même fenêtre (copie sans valeurs, puis formulaire « Partager une fiche »).

**EN** — Profiles shared by DunenScope users: each describes a model (protocol, link, names, units and scales of the
rows). In DunenScope: **Other device** page → **Open a profile…** → **Online library…**. The values in a shared
profile are never used. To offer yours: **Share my profile…** button in the same window (a copy without values,
then the "Share a profile" form).
